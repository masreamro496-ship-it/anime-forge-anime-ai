## المشكلة
زر «إنشاء مشروع» في صفحة `/shorts` لا يفتح صفحة إنشاء المشروع، وأنت تريد التأكد أن النموذج يحتوي على كل الحقول (عنوان، وصف، سعر، رقم فودافون كاش، رفع ملف) وزر «شراء» في صفحة المشروع يعمل صحيح.

## السبب المرجّح
- مسار `/shorts/upload` يستخدم `beforeLoad` يستدعي `supabase.auth.getUser()`. لو الجلسة غير محمّلة وقت الضغط (أو فشلت الشبكة) يبقى المستخدم في `/shorts` بدون أي رسالة، فيبدو الزر «لا يعمل».
- الزر معمول كـ `<Link>` فقط بدون أي fallback أو مؤشّر تحميل.
- نموذج الرفع موجود فعلياً بكل الحقول، لكن المستخدم لا يصل إليه أصلاً بسبب ما سبق.

## الخطّة

### 1) إصلاح الانتقال إلى صفحة «إنشاء مشروع»
- في `src/routes/shorts.tsx`: استبدال الزرّين (في الهيدر وفي البطاقة الذهبية) بأزرار تقوم بـ `useNavigate()` يدوياً مع فحص الجلسة:
  - لو المستخدم مسجّل دخول → `navigate({ to: "/shorts/upload" })`.
  - لو لا → `navigate({ to: "/login", search: { redirect: "/shorts/upload" } })`.
- إضافة `toast` خطأ لو فشل الانتقال.
- في `src/routes/shorts.upload.tsx`: تبسيط `beforeLoad` ليستخدم الجلسة المخزّنة (`getSession`) بدل `getUser` لتفادي توقف الراوتر لو الشبكة بطيئة.

### 2) تنظيف وتقوية نموذج «إنشاء مشروع» (`src/routes/shorts.upload.tsx`)
يبقى النموذج بنفس الحقول لكن مع تحسين الترتيب والوضوح:
1. **عنوان المشروع** (نص، إلزامي ≥ 2 حرف).
2. **وصف المشروع** (نص طويل، إلزامي ≥ 5 أحرف).
3. **السعر بالدولار** (رقم > 0، حقل ذهبي بارز).
4. **رقم فودافون كاش** — يظهر ثابتاً `01080390782` (للقراءة فقط) مع نص توضيحي «الدفع يتم لهذا الرقم».
5. **رفع ملف الفيديو** (MP4، حد أدنى دقيقة، حد أقصى 10 دقائق للمجاني / 30 دقيقة للـ Pro، تحويل تلقائي 360p).
6. **زر «نشر المشروع»** (ذهبي كبير) + شريط تقدّم.

تحسينات إضافية:
- التحقّق من الحقول قبل بدء رفع الفيديو (حالياً يُتحقّق بعد الرفع — سيتم نقله للأعلى لتوفير الوقت).
- رسائل خطأ عربية واضحة لكل حالة.

### 3) إصلاح صفحة تفاصيل المشروع وزر «شراء» (`src/routes/shorts.$id.tsx`)
- التأكد من ظهور: العنوان، الوصف، السعر، المدة، عدد المشاهدات، صورة مصغّرة.
- زر «شراء» (أخضر) ينادي `request_purchase` ويُظهر رقم البائع للتحويل + زر اتصال.
- بعد الدفع: زر «طلب تفعيل» (موجود) + حالة الانتظار + حالة الموافقة.
- إضافة زر «رجوع للسوق» في أعلى الصفحة (موجود) وزر «الرئيسية».

### 4) لا تغييرات على قاعدة البيانات
كل الـ RPCs المطلوبة موجودة بالفعل: `create_project`، `request_purchase`، `get_project_video_path`.

## الملفات التي ستتغيّر
- `src/routes/shorts.tsx` — تحويل الأزرار إلى `useNavigate` مع فحص الجلسة.
- `src/routes/shorts.upload.tsx` — نقل التحقق من الحقول للأعلى + تبسيط `beforeLoad`.
- `src/routes/shorts.$id.tsx` — مراجعة بصرية لزر الشراء والعنوان والسعر.
